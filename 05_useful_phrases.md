# Useful Phrases for the Speaking Exam & Daily Life

> These are essential phrases you MUST know for the A2 speaking exam.
> Practise saying them out loud every day!

---

|-------|---------|-----------------|
| Dobrý den! | Good day / Hello! | Formal |
| Ahoj! | Hi! | Informal |

## 2. Introducing Yourself — Představení

**Practice this sequence until it feels natural:**

> Dobrý den, jmenuji se Prince.
> Jsem z Jihoafrické republiky.
> Bydlím v Praze devět let.
> Pracuji jako účetní.
> Studuji češtinu, protože chci získat české občanství.

| Czech phrase | English |
|-------------|---------|
| Jmenuji se... | My name is... |
| Jsem z... | I am from... |
| Bydlím v... | I live in... |
| Pracuji jako... | I work as... |
| Studuji... | I study... |
| Je mi... let. | I am ... years old. |
| Mám rodinu — manžela/manželku a děti. | I have a family — husband/wife and children. |
| Jsem ženatý / vdaná. | I am married (m/f). |
| Jsem svobodný / svobodná. | I am single (m/f). |

## 3. At the Doctor — U lékaře **[EXAM LIKELY]**

| Czech | English |
|-------|---------|
| Potřebuji se objednat k doktorovi. | I need to make an appointment with the doctor. |
| Bolí mě... | My ... hurts. |
| Jsem nemocný/á. | I am ill. |
| Mám teplotu. | I have a fever. |
| Mám rýmu. | I have a cold. |
| Kašlu. | I have a cough / I am coughing. |
| Necítím se dobře. | I don't feel well. |
| Od kdy? | Since when? |
| Jak dlouho? | For how long? |
| Recept, prosím. | The prescription, please. |
| Kde je nejbližší lékárna? | Where is the nearest pharmacy? |

**Key numbers:**
- Ambulance: **155**
- Police: **158**
- European emergency: **112**

## 6. At a Restaurant — V restauraci **[EXAM VERY LIKELY]**

| Czech | English |
|-------|---------|
| Stůl pro dvě osoby, prosím. | A table for two, please. |
| Jídelní lístek, prosím. | The menu, please. |
| Co si dáte? | What will you have? (waiter asks) |
| Dám si... | I'll have... (ordering) |
| Doporučujete něco? | Do you recommend something? |
| Co je dnešní specialita? | What is today's special? |
| Jsem vegetarián/vegetariánka. | I am vegetarian (m/f). |
| Neallergický/á jsem na... | I am not allergic to... |
| Mám alergii na... | I am allergic to... |
| To je všechno, děkuji. | That's all, thank you. |

| Zvlášť nebo dohromady? | Separately or together? (waiter asks) |
| Dohromady, prosím. | Together, please. |
| Moc mi chutnalo. | I really enjoyed the food. |

## 12. Key Connecting Words — Spojky

| Czech | English |
|-------|---------|
| a | and |
| ale | but |
| nebo | or |
| protože | because |
| proto | therefore |
| když | when / if |
| potom / pak | then / afterwards |
| také / taky | also |
| tedy | so / therefore |
| i když | even though |
| jestli | if |
| že | that (conjunction) |

**Example sentence using connectors:**
> Studuji češtinu, **protože** chci získat občanství, **ale** čeština je těžká. **Když** nerozumím, ptám se učitelky.
>
> *(I study Czech because I want to get citizenship, but Czech is hard. When I don't understand, I ask the teacher.)*

## 13. Czech Alphabet — Pronunciation Tips

| Letter | Sound (approx.) | Example |
|--------|----------------|---------|
| á | long "ah" | pátek |
| č | "ch" in "church" | čaj |
| ě | "ye" | věta |
| ch | strong "h" from back of throat | chléb |
| í / ý | long "ee" | pivo, bílý |
| j | "y" in "yes" | jídlo |
| ň | "ny" in "canyon" | keň |
| ó | long "oh" | — |
| ř | unique sound (rolled r + zh) | řeka, Dvořák |
| š | "sh" in "ship" | škola |
| ú / ů | long "oo" | úřad, dům |
| ž | "s" in "treasure" | život |

**Pronunciation of "je":** words like -ie, -je endings = [ye] sound
- fotografIE = [fotografiYE]
- policiE = [policiYE]
