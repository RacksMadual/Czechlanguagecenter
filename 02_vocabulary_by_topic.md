## Topic 1: Greetings & Introductions — Pozdravy a představení

### Greetings
| Czech | English | When to use |
|-------|---------|-------------|
| **Dobrý den!** | Good day / Hello | Formal |
| **Ahoj!** | Hi / Bye | Informal |
| **Dobré ráno!** | Good morning | Formal/informal |
| **Dobrý večer!** | Good evening | Formal |
| **Na shledanou!** | Goodbye | Formal |
| **Čau!** | Bye | Informal |

### Asking how someone is
| Czech | English |
|-------|---------|
| Jak se máte? | How are you? (formal) |
| Jak se máš? | How are you? (informal) |
| Mám se dobře. | I'm fine. |
| Mám se špatně. | I'm not well. |
| Ujde to. | So-so / Not bad. |
| Jsem trochu nemocný/á. | I'm a bit ill. |

### Personal information **[EXAM]**
| Czech | English |
|-------|---------|

| Odkud jste? | Where are you from? |

### Body parts (exam topic!)

| břicho | stomach |

### Saying what hurts
**Formula: Bolí mě + body part (accusative)**
- Bolí mě hlava. *(My head hurts.)*
- Bolí mě záda. *(My back hurts.)*
- Bolí mě v krku. *(My throat hurts.)*
